# GitHub Release Checklist

1. Create a public repository named `matrix-terminal`.
2. Upload the repository contents.
3. Set the repository description to:
   `A Windows terminal UI with Matrix and MikroTik-inspired themes, powered by a native Windows ConPTY backend.`
4. Add topics: `windows`, `terminal`, `cmd`, `matrix`, `mikrotik`, `routeros`, `wpf`, `dotnet`, `csharp`.
5. Create the first release as `v0.2.1`.
6. Attach the ZIP source package.
7. In the release notes, summarise `CHANGELOG.md`.
